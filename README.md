# SecureDoc
## Cloud-Based Secure Student Document Management System

SecureDoc is a web-based application developed to help
students organize and manage their academic documents.

### Features
- User Registration and Login
- Firebase Authentication
- Secure Firestore Rules
- Document Upload
- Document Categorization
- Search and Filter
- Document Preview and Delete
- Dashboard Statistics
- Activity Tracking

### Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- IndexedDB

### Storage Information
Firebase Firestore stores document metadata and activity
records. Actual uploaded files are stored locally in the
browser using IndexedDB.
